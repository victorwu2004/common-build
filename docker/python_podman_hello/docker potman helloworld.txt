## Quick Start

### Step 1: Install Podman

```bash
# Linux (Fedora/RHEL)
sudo dnf install podman

# Linux (Ubuntu)
sudo apt install podman

# macOS
brew install podman
podman machine init
podman machine start

# Windows: https://podman.io/getting-started/installation
```

### Step 2: Extract and Run

```bash
unzip python_podman_hello.zip
cd python_podman_hello

# Linux/Mac
./run.sh

# Windows
run.bat
```

That's it! The script will:
1. Build the container image
2. Clean up old containers  
3. Run the app with pretty output

## Manual Commands (If You Want to Learn)

```bash
# Build image
podman build -t python-hello .

# Run with defaults
podman run --rm python-hello

# Run with custom env vars
podman run --rm \
  -e NAME="Alice" \
  -e INTERVAL="2" \
  -e MESSAGE="My container works!" \
  python-hello

# List images
podman images

# List running containers
podman ps

# Follow logs of running container
podman logs -f hello-container
```

## What Makes This a Good Learning Example

1. **Non-root user** — Security best practice (line 25 in Dockerfile)
2. **Layer caching** — `requirements.txt` copied before code (rebuilds faster)
3. **Environment variables** — Configure without rebuilding
4. **`.dockerignore`** — Keeps image small & secure
5. **Graceful shutdown** — Handles Ctrl+C properly (signal_handler)
6. **`PYTHONUNBUFFERED=1`** — Real-time log output

## Docker Compatibility

The same Dockerfile works with Docker! Just swap the command:

```bash
docker build -t python-hello .
docker run --rm python-hello
```

Podman is a drop-in replacement for Docker with these benefits:
- **No daemon** — More secure (no root process)
- **Rootless by default** — Runs without sudo
- **Same commands** — All Docker knowledge transfers
