On the TradeStation API: a static GitHub Pages site can't safely call it — TradeStation uses OAuth2 whose token exchange needs a client secret that can't live in public browser code, and its endpoints don't send CORS headers, so the browser blocks the request. This ledger uses Stooq (free, keyless, CORS-open) for price history instead. To use live TradeStation fills, run a small local script that pulls your positions and writes them into the CSV this page imports — keeping your secret off the public page.
Deploy: drop this file into a repo as index.html → Settings → Pages → deploy from branch. Prices via stooq.com.
